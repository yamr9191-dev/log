# إمبراطورية سلاسل الإمداد

لعبة تعليمية تفاعلية باللغة العربية عن إدارة سلاسل الإمداد.

## تشغيل اللعبة
افتح ملف `index.html` في المتصفح.

## نشر اللعبة باستخدام GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملف `index.html` إلى المجلد الرئيسي للمستودع.
3. افتح **Settings → Pages**.
4. من **Build and deployment** اختر **Deploy from a branch**.
5. اختر فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.

اللعبة تعمل مباشرة دون تثبيت أي مكتبات أو إعداد خادم.
